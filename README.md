## 📌 Overview

**Kuro Cinema** is a mobile application engineered by **Mochamad Rahdian** to provide users with a seamless, cinematic movie discovery experience. Powered by **The Movie Database (TMDB) API**, it brings real-time trending movies, top-rated selections, interactive swiping UI, and instant search capabilities right to your fingertips.

---

## ✨ Key Features

- **🔥 Trending Banner Carousel:** Auto-playing, high-resolution backdrop carousel showcasing today's trending movies using `carousel_slider`.
- **🃏 Interactive Card Swiper:** Swipe through top-rated movies with smooth gesture animations powered by `flutter_card_swiper`.
- **🔍 Real-Time Movie Search:** Search favorite movies instantly with live filtering and dynamic HTTP updates.
- **📖 Comprehensive Movie Details:** Detailed view featuring movie backdrops, overview synopsis, release date, and TMDB ratings.
- **🌙 Dark Cinema Mode:** A sleek black-and-red UI aesthetic engineered for an immersive viewing experience.

## 🚀 Getting Started

Follow these steps to get a local copy up and running on your device or emulator.

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.0.0 or higher)
- Android Studio / VS Code with Flutter extension
- A free API Key from [The Movie Database (TMDB)](https://www.themoviedb.org/settings/api)
